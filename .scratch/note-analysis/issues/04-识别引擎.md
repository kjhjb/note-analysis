# 04 — 识别引擎：多模态 LLM 提取

**What to build:** AI Agent（复用 Ticket 01 的 Agent 框架）以整卷上下文视角调用 LLM（使用 Anthropic 兼容协议），对全卷所有框选区一次性或分批识别。Agent 将全部框选区的上下文传递给 LLM，使其准确判断每一道题的黑字原题和红字笔记，识别 LaTeX 公式，保留原题中的图片，并对每个文字区域输出置信度评分（用于下一阶段的不确定处理）。用户跑 `python main.py recognize <exam-dir>` 后，Agent 将识别结果写入 JSON。

**Blocked by:** 03 — Web UI 框选微调

**Status:** ready-for-agent

- [ ] Agent 编排识别流程：加载已确认 bbox 的 JSON → 裁剪各框选区图片 → 构造含**整卷上下文**的 Prompt（全部框选区图片 + 位置关系描述）
- [ ] Prompt 设计：要求 LLM 区分黑字原题与红字笔记，公式输出 LaTeX，保留图片描述，对每个文字区域输出 `confidence` 评分（0~1）
- [ ] 上下文传递：Agent 确保一次 LLM 调用中包含多个框选区的上下文（而非单题独立调用），让 LLM 理解题目之间的关联和结构
- [ ] 颜色语义：使用红色大类（非纯色）检测，凡属于红色系的笔记文字归类为 `annotations`
- [ ] 置信度标记：LLM 返回中 `confidence < threshold` 的区域自动标记为 `uncertainRegions[]`，Agent 保持原始猜测文本
- [ ] 输出写入 JSON：Agent 解析 LLM 返回并填充 `questionText`、`annotations`、`images`、`uncertainRegions`
- [ ] `recognize` 子命令：Agent 接收试卷目录，执行全卷识别

**Blocking:** 05 不确定区域处理
