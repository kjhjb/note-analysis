# 02 — 框选引擎

**What to build:** 纯传统 OpenCV 计算机视觉模块（不涉及 LLM 或 Agent），自动检测试卷照片中各大题的自然段边界。用户跑 `python main.py box <exam-dir>` 时，系统加载 JSON 骨架、读取每张照片、用 CV 方法计算 bbox 坐标、写入 JSON，并生成一张带红框标注的预览图片供核对。

**Blocked by:** 01 — 项目骨架与核心数据模型

**Status:** ready-for-agent

- [ ] OpenCV 图像预处理：灰度化、二值化、去噪、倾斜校正
- [ ] 自然段边界检测：轮廓分析/投影法检测题目之间的空白间隔，合并为大题级 bbox
- [ ] bbox 坐标写入 JSON 中对应框选区的 `bbox` 字段
- [ ] 生成预览图：在原图上绘制红色 bbox 矩形框，保存为 `*_bbox_preview.jpg`
- [ ] `box` 子命令：接收试卷目录路径，遍历所有照片执行框选

**Blocking:** 03 Web UI 框选微调
