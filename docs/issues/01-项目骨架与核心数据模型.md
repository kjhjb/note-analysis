# 01 — 项目骨架与核心数据模型

**What to build:** 搭建 Python 项目骨架，定义整个系统的心脏——数据模型。用户首次跑 `python main.py init <exam-dir>` 时，能扫描试卷照片目录，生成一个带时间戳的空 JSON 骨架文件（`笔记_YYYYMMDD_HHmm.json`），内含符合领域术语表的数据结构：框选区列表、不确定区域、薄弱点等字段。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] Python 项目初始化：pyproject.toml、虚拟环境、依赖清单（opencv-python, httpx, pydantic, fastapi, uvicorn, openai/anthropic SDK 等）
- [ ] **AI Agent 编排层**：Agent 核心（LLM 调用管理器 + 上下文窗口 + 工具调用），所有涉及 LLM 的操作（识别、审查、分析、渲染）均由 Agent 编排而非硬编码逻辑
- [ ] **API 协议**：所有 LLM 调用使用 **Anthropic 兼容协议**（`/v1/messages` 端点），兼容 Anthropic、OpenAI 或其他兼容服务
- [ ] **Skill 加载能力**：Agent 可从本地路径读取 SKILL.md 并按其中定义的工作流执行任务（为 Ticket 07 使用学霸笔记 skill 做准备）
- [ ] Pydantic 数据模型：试卷（exam_id, 照片列表, 框选区列表, 生成时间）、框选区（id, bbox, 原题, 红笔笔记, 不确定区域列表）、不确定区域（bbox, 原始猜测, 用户确认）、薄弱点（知识点, 错误次数, LLM 建议）
- [ ] JSON 序列化/反序列化：模型 ↔ 文件，自动按 `笔记_YYYYMMDD_HHmm.json` 格式命名
- [ ] CLI 入口：`main.py` 用 click/argparse 绑定子命令（init, box, serve, recognize, review, render, analyze）
- [ ] `init` 子命令：扫描目录内的图片文件，生成初始 JSON 骨架

**Blocking:** 02 框选引擎
