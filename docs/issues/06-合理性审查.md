# 06 — 合理性审查

**What to build:** AI Agent（复用 Ticket 01 的 Agent 框架 + Anthropic 兼容协议）在所有不确定区域确认后，调用 LLM 复核文本逻辑一致性——两个维度：（1）原题文字和红字笔记在逻辑上是否自洽（例如题目条件是"x=5"但红字写"x=3"且无解释，属于字迹没改对）；（2）上一阶段标记的 `uncertainRegions` 中字迹不清的地方是否已被用户正确修正。用户跑 `python main.py review <exam-dir>` 时 Agent 执行审查，结果追加到 JSON 中。

**Blocked by:** 05 — 不确定区域处理

**Status:** ready-for-agent

- [ ] 审查 Prompt：Agent 调用 LLM 对每个框选区，比较 `questionText` 和 `annotations`，判断逻辑一致性
- [ ] 交叉检查：对每个 `uncertainRegion`，对比 `userConfirmed` 内容与周围上下文是否一致
- [ ] 输出格式：每个框选区标记 `reviewStatus`（consistent / inconsistent / uncertain）和 `reviewNotes`（矛盾说明）
- [ ] 结果写入 JSON：在框选区层级添加 `review` 字段
- [ ] `review` 子命令：接收试卷目录，输出审查摘要到控制台并更新 JSON

**Blocking:** 07 HTML 渲染
