# 08 — 多试卷累积与薄弱点分析

**What to build:** AI Agent（复用 Ticket 01 的 Agent 框架 + Anthropic 兼容协议）加载目录中多份 JSON 数据，本地按知识点统计错误频次（降序排列），再调用 LLM 生成自然语言提升建议（使用高中数学、物理专有名词）。用户跑 `python main.py analyze <exams-dir>` 时 Agent 输出分析报告，并更新 JSON。

**Blocked by:** 07 — HTML 渲染引擎

**Status:** ready-for-agent

- [ ] 本地统计引擎：遍历多份 JSON，按知识点/题型聚合错题频次，降序输出列表
- [ ] LLM 提示词：要求使用高中数学、物理专有名词，基于频次数据生成针对性提升建议
- [ ] 输出格式：更新对应 JSON 中的 `weakPoints[]` 字段（知识点, 错误次数, LLM 建议）
- [ ] 聚合分析 HTML（可选）：生成独立的分析结果 HTML 或更新已有笔记页
- [ ] `analyze` 子命令：接收试卷/目录路径，执行分析并输出结果
